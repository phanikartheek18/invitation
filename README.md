# Kalyani & Nandu — Digital Engagement Invitation

A responsive, elegant digital invitation website for Kalyani and Nandu's engagement ceremony.

## Event Details
- **Date & Time:** Wednesday, 25 November 2026, 9:30 AM onwards
- **Venue:** Hotel Surya Grands, Vijayawada, Andhra Pradesh
- **Location Map:** [Google Maps](https://maps.app.goo.gl/ZRQBBzj48xZXCBuy7?g_st=ic)

## Features
- Minimal opening screen with "Open Invitation" transition
- Interactive venue map integration & direct calendar download (.ics)
- Live event countdown timer
- Web Share API support for 1-click sharing
- Subtle falling floral motifs with reduced-motion accessibility support

## Deployment
This project is static HTML/CSS/JS with zero build steps required. It deploys automatically to platforms like **GitHub Pages** or **Vercel**.
