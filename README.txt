KALYANI & NANDU — DIGITAL ENGAGEMENT INVITATION

Files:
- index.html: responsive digital invitation website
- engagement-invitation.png: original invitation poster

What's different:
- Minimal opening screen with an "Open Invitation" button
- Original invitation poster is the main information source
- Removed duplicated date, venue, and family-detail sections
- Interactive venue map, calendar download, share button, and countdown
- Subtle falling decorative motifs, with reduced-motion accessibility

Local preview:
Open index.html in a browser, or run a local server from this folder.

Deploy to Vercel:
1. Upload this folder to a GitHub repository.
2. Sign in at https://vercel.com and choose Add New > Project.
3. Import the repository and click Deploy.
4. Share the generated .vercel.app URL.
